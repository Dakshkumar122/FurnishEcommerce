# HomeFurnish 🛋️

HomeFurnish is a modern and responsive furniture website built using HTML, SCSS, JavaScript, Bootstrap 5, Swiper.js, and Vite.

## 🚀 Features

- Responsive Design
- Modern UI/UX
- Bootstrap 5 Layout
- Swiper Slider Integration
- SCSS Styling
- Fast Development with Vite

## 🛠️ Technologies Used

- HTML5
- SCSS / CSS3
- JavaScript
- Bootstrap 5
- Swiper.js
- Vite

## 📂 Project Structure

```bash
src/
 ├── assets/
 │    ├── images/
 │    ├── js/
 │    └── scss/
 ├── index.html
 ├── about.html
 ├── contact.html
 ├── products.html
 └── testimonials.html
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/HomeFurnish.git
```

Go to the project folder:

```bash
cd HomeFurnish/furnish-1.0.0
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
